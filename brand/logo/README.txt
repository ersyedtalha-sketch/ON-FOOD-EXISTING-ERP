ON FOOD — LOGO FILES
====================

WHAT TO USE ON YOUR WEBSITE
---------------------------
Header / navbar        onfood-logo-horizontal.svg   (or .png)
Dark background        onfood-logo-reversed.svg / onfood-logo-horizontal-reversed.svg
Stacked / hero         onfood-logo-primary.svg      (or .png)
Favicon & app icon     onfood-icon-square.png       (800 x 800)
Leaf symbol alone      onfood-leaf-mark.svg


SVG vs PNG
----------
SVG  — infinitely sharp at any size, tiny file. Best for your website.
       Use it in HTML like:  <img src="onfood-logo-horizontal.svg" alt="ON FOOD" width="220">
       The EB Garamond font is EMBEDDED inside each SVG file, so the wordmark renders
       in the correct typeface on every device with no setup and no internet font
       loading. Nothing else to install.

PNG  — exported at 4x resolution with a transparent background. Works everywhere,
       every browser, every phone, no font needed. Use this if you want zero setup.
       Always display it at 1/4 of its pixel width or smaller so it stays crisp on
       retina and high-density mobile screens.
       Example: onfood-logo-horizontal.png is 1416px wide → display at 354px or less.

The leaf-mark SVGs are pure vector shapes with no font at all — they render
identically everywhere.

TYPEFACES
---------
EB Garamond Bold (700) — the "ON FOOD" wordmark.
Lato Bold (700)        — the tagline "FRESH, HEALTHY, DELICIOUS" (uppercase, wide tracking).
Both free, open source, SIL Open Font License 1.1. Available on Google Fonts.
Both are embedded inside the SVG files, so nothing needs installing.

The square app icon / favicon carries the wordmark only — the tagline is not legible
at icon sizes.


CLEAR SPACE
-----------
Keep empty space around the logo equal to the height of the leaf on all sides.
Do not stretch, recolour, rotate, or add effects to the logo.
Minimum width on screen: 150px horizontal lockup, 130px stacked lockup — below this
the tagline stops being legible; use the wordmark-only leaf mark instead.
